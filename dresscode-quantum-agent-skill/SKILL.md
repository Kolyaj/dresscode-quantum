# Quantum (dresscode-quantum)

`dresscode-quantum` — библиотека реактивных «квантов» для проектов DressCodeJS: объекты с изменяющимся значением (`getValue`/`setValue`), которые извещают слушателей о смене и связываются в синхронно обновляющиеся цепочки. Собственной сборки нет: код компилируется вместе с вашим кодом dresscodejs. О сборщике — скил dresscode-agent-skill, о зависимости `Bricks` — скил dresscode-bricks-agent-skill.

## Подключение к проекту

1. `npm install --save dresscode-quantum` (это runtime-зависимость; `dresscode-bricks` ставится вместе с ней — он объявлен в `dependencies` пакета).
2. В проектном `.dresscode` указываются прямые зависимости проекта — библиотеки, используемые кодом проекта:

```
node_modules/dresscode-quantum/lib
```

Библиотека самодостаточна: её `lib/.dresscode` сама объявляет путь к `dresscode-bricks/lib`, поэтому Bricks подтягивается в сборку вместе с ней — дублировать в проекте внутренние зависимости Quantum не нужно. Если проект использует Bricks напрямую (в своём коде) — укажите его путь в `.dresscode` тоже.

## Лексика

| Термин | Смысл |
|---|---|
| **Квант** | объект с изменяющимся значением (`Quantum.Quant`): хранит значение и извещает слушателей о его смене. Базовая единица библиотеки. |
| **when-цепочка** | цепочка квантов, связанных `when(fn)`: каждый следующий пересчитывает своё значение из предыдущего и меняется синхронно с ним. |
| **Модификатор** | функция-преобразователь значения родителя (`fn` у `when`/`transform`). |
| **Развёрнутое значение** | значение кванта, если в нём лежит квант: считается значение вложенного (рекурсивно, до «листовой» величины). |
| **touch** | принудительное извещение об изменении, чья ссылка не изменилась (внутренности объекта/массива поменялись на месте). |
| **Комбинатор** | квант, зависящий от набора исходных квантов; его значение — массив их значений (`Quantum.combine`). |
| **Array-квант** | `Quantum.Array`: квант со значением-массивом и событиями изменения состава (`insert`/`remove`/`splice`). |
| **Источник зависимости** | квант, за которым следует другой: родитель в when-цепочке, вложенный квант, родительский Array у `transform`, ребёнок комбинатора. У кванта может быть несколько источников. |
| **Активность** | квант активен, когда у него есть хотя бы один слушатель. Пассивный квант источникам не следует и пересчитывает значение по требованию (`getValue`). |

## Краткая шпаргалка

| API | Что делает |
|---|---|
| `new Quantum.Quant(value)` | квант; если `value` — квант, разворачивается до его значения. |
| `Quantum.quantize(value)` | value в квант; уже квант — возвращается как есть. |
| `Quantum.combine(array)` | комбинатор из набора квантов/значений. |
| `Quantum.debounce(quant, delay)` | «дебаунсенный» квант. |
| `Quantum.series(values, delay)` | квант, последовательно проигрывающий значения. |
| `Quantum.getTimer(timeout)` | квант-часы (`Date.now()`), период `timeout` мс (по умолчанию 50). |
| `Quantum.format(str, …args)` | квант со строкой из шаблона `str` (постоянные части + кванты). |
| `Quantum.DOM.getDocumentScroll(doc)` | квант `[left, top]` прокрутки, обновляется на `scroll`. |
| `Quantum.DOM.getViewportSize(doc)` | квант `[width, height]`, обновляется на `resize`. |
| `Quantum.DOM.createWatcher(doc, event, getValue)` | строитель кастомных «оконных» квантов. |

## `Quantum.Quant`

| Метод | Контракт |
|---|---|
| `getValue()` | развёрнутое значение. |
| `setValue(value)` | ставит значение. Та же ссылка (`===`) — ни событий, ни изменений. Если значение — квант, квант начинает следить за ним (вложенный квант — ещё один источник зависимости). |
| `touch()` | извещает «на месте»: fire `prioritychange` (с `touched: true`) и `change` с текущим значением. |
| `when(callback, ctx)` | новый квант, зависящий от этого: `callback` преобразует значение исходного в значение нового. |
| `whenNotNull(fn, ctx)` | как `when`, но `fn` вызывается только для значений ≠ `null`/`undefined`; null-значения проходят без изменений. |
| `whenNull(fn, ctx)` | как `when`, но `fn` — только для `null`/`undefined`; остальные значения проходят без изменений. |
| `spread(fn, ctx)` | как `when`, но элементы значения-массива передаются `fn` раздельными аргументами. |
| `addEventListener(name, fn)` / `removeEventListener(name, fn)` | подписка/снятие слушателя. Первый слушатель **активирует** квант (он начинает следовать источникам), последний — деактивирует. |

**События.** Оба — `change` и `prioritychange` — возникают, только когда развёрнутое значение фактически изменилось (`!==`); а также на `touch()` (`change` + `prioritychange` с `touched: true`). Событие `prioritychange` — «техническое»: на нём работают внутренние механизмы библиотеки (when-цепочки, Array, Комбинатор), но вы тоже можете на него подписаться — для него доступен флаг `touched`.

Слушатель получает объект события единственным аргументом; `this` в нём — квант:

| Свойство | Смысл |
|---|---|
| `type` | имя события (`'change'` / `'prioritychange'`). |
| `target` | квант, на котором событие произошло. |
| `value` | значение после события. |
| `prevValue` | значение до события. |
| `touched` | у `prioritychange`: `true`, если вызвано `touch()` (тогда `value === prevValue`). |

```js
source.addEventListener('change', function(evt) {
    console.log(evt.value, evt.prevValue);   // новый, старый
});
```

## `Quantum.Array`

Наследует всё от `Quantum.Quant` (значение — массив; `change` здесь возникает на новую ссылку) и добавляет методы массива и события изменения состава. Конструктор принимает массив, `null`/`undefined` (→ пустой массив); не массив — `TypeError`.

**События** (все три возникают **до** мутации; `change` — **после**, на новую ссылку):

| Событие | Когда | Аргумент |
|---|---|---|
| `insert` | для каждого добавляемого элемента | `index`, `item`, `nextItem` (элемент после вставленного блока, или `undefined`) |
| `remove` | для каждого удаляемого элемента | `index`, `item` |
| `splice` | один раз, после всех `insert`/`remove` одной операции | `start`, `deleteCount`, `insertItems` |

**Методы** (все вызывают соответствующие события + `change`):

| Метод | Контракт |
|---|---|
| `append(items)` / `prepend(items)` | в конец / в начало; `items` **обязательно массив** — иначе `TypeError`. |
| `push(…items)` / `unshift(…items)` | varargs (каждый аргумент — элемент); возвращает новую длину. |
| `pop()` / `shift()` | убирает последний / первый; возвращает элемент (`undefined`, если массив пуст). |
| `clear()` | убирает все элементы. |
| `splice(start, deleteCount, insertItems)` | как `Array.prototype.splice`: `insertItems` обязателен массив (иначе `TypeError`), отрицательный `start` — от конца, ничего не удалить/не вставить — ни событий, ни изменений; возвращает удалённые. |
| `isEmpty()` | квант с булевым «пуст ли массив»; при повторных вызовах — тот же квант. |
| `remove(callback, ctx)` | удаляет элементы, для которых `callback(item)` истинен; на каждый элемент — отдельные `remove`/`splice`/`change`. |
| `transform(transformer, ctx)` | новый Array-квант: `transformer(item, index)` сопоставляет элементы исходного; следует за изменениями состава источника (`splice`). |

## `Quantum.Combinator`

Обычно не конструируется напрямую — через `Quantum.combine(quants)`: источники — кванты и/или обычные значения, значение комбинатора — массив их значений в заданном порядке (обычные значения проходят без изменений). Обновляется, когда меняется хотя бы один из источников. **`setValue` не поддерживается — бросает `Error`**: значение всегда выводится из источников.

## `Quantum.DOM`

Кванты браузерных величин: `getDocumentScroll()` → `[left, top]` (событие `scroll`), `getViewportSize()` → `[width, height]` (событие `resize`). Оба **кэшируются глобально один на всё**: повторный вызов возвращает тот же квант, а документ/окно определяется первым вызовом. `createWatcher(doc, event, getValue)` — строитель для кастомных квантов, обновляющихся на событии окна.

## Типовые паттерны

```js
// when-цепочка: цепочка пересчитывается синхронно при изменении источника
var source = new Quantum.Quant(5);
var squared = source.when(function(value) { return value * value; });

// два независимых значения → одно
var total = Quantum.combine([price, quantity]).when(function(v) {
    return v[0] * v[1];
});

// строка из шаблона: обновится при изменении любого из квантовых аргументов
var label = Quantum.format('Цена: %s, в наличии: %s', price, count);

// обратный отсчёт: when-цепочка с внутренними часами
var remaining = Quantum.getTimer(1000).when(function(now) { return deadline - now; });

// условие по скроллу
var pastHeader = Quantum.DOM.getDocumentScroll().when(function(pos) {
    return pos[1] > 500;
});
```

## Нюансы

- **`change` — только на реальное изменение** (`!==` развёрнутого значения). Объект/массив, изменившийся «на месте», `change` не порождает — для этого есть `touch()`.
- **Активность — по слушателям.** Квант без слушателей пассивен: не следует источникам, а `getValue()` пересчитывает значение при обращении. when-цепочка с никем не подписанным концом пересчитается в момент первой подписки — и далее синхронно. Комбинатор подписывает источники только на время своей активности.
- **События Array идут до мутации.** В обработчике `insert`/`remove` массив ещё не изменился; `change` приходит уже с новой ссылкой.
- **Глобальные кэши переживают всё время жизни страницы**: `getTimer(timeout)` возвращает один и тот же квант для одного `timeout`; DOM-катеры — один на всё. В тестах под fake-timers кэш таймеров жив между тестами — использовать разные таймауты.
- **`debounce`** берёт значение источника в момент окончания интервала (новое изменение сбрасывает отсчёт); **`series`** ставит первое значение сразу, далее — через `delay` мс (по умолчанию 1).
