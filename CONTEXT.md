# dresscode-quantum: лексика

- **Квант** — объект с изменяющимся значением: хранит значение и извещает слушателей о его смене (getValue/setValue). Базовая единица библиотеки.
- **when-цепочка** — цепочка квантов, связанных методом `when(fn)`: каждый следующий пересчитывает своё значение из предыдущего и меняется синхронно с ним.
- **Модификатор** — функция, преобразующая значение родительского кванта в значение дочернего (аргумент `when`/`transform`).
- **Развёрнутое значение** — значение кванта, в котором лежит квант: считается значением вложенного (рекурсивно, до «листовой» величины).
- **touch** — принудительное извещение об изменении значения, чья ссылка не изменилась (внутренности объекта/массива поменялись на месте).
- **Комбинатор** — квант, зависящий от набора исходных квантов; его значение — массив их значений (`Quantum.combine`).
- **Array-квант** (`Quantum.Array`) — квант со значением-массивом и событиями изменения состава (insert/remove/splice).
